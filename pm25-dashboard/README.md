# PM2.5 ภาคเหนือตอนบน — Dashboard

เว็บแสดงข้อมูลฝุ่น PM2.5 รายวันของสถานีตรวจวัดในภาคเหนือตอนบน 9 จังหวัด ใช้ HTML + JavaScript ล้วน ไม่ต้องติดตั้งหรือ build
**ข้อมูลทั้งหมดเก็บเป็นไฟล์ในโฟลเดอร์ `data/` ของรีโปนี้ ไม่ได้ฝังในหน้าเว็บ** และอัปเดตเองได้ด้วยไฟล์ดิบ Excel/CSV รูปแบบเดิมผ่านหน้าหลังบ้าน

> **วิธีอัปเดตข้อมูลทีละขั้น (พร้อมภาพหน้าจอ): เปิด [`manual.html`](manual.html)** — เพิ่ม/แก้/ลบข้อมูล เพิ่มสถานี RONI บันทึกขึ้น GitHub ย้อนกลับเมื่อพลาด ปัญหาที่พบบ่อย

- ชุดข้อมูล **11 สถานี** (กรมควบคุมมลพิษ ปี 2012–2025): แผนที่ ความเข้มข้น วันที่เกินมาตรฐาน Baseline กราฟ
- ชุดข้อมูล **3 สถานี** (CM · LP · LI มี.ค.–ส.ค. 2026): แผนที่ ความเข้มข้น วันที่เกินมาตรฐาน

## โครงสร้างโฟลเดอร์

```
pm25-dashboard/                  ← ชื่อรีโปตั้งอย่างอื่นก็ได้
├── index.html                   หน้าบ้าน
├── admin.html                   หลังบ้าน (นำเข้าไฟล์ดิบ แก้ข้อมูล บันทึกขึ้น GitHub)
├── manual.html                  คู่มือการอัปเดตข้อมูล
├── .nojekyll                    ไฟล์เปล่า บอก GitHub Pages ไม่ต้องใช้ Jekyll
├── README.md                    ไฟล์นี้
├── data/
│   ├── config.js                สถานี พิกัด ชุดข้อมูล ค่ามาตรฐาน (37.5/15.0) เกณฑ์ข้อมูลครบ ค่า RONI
│   ├── geo.js                   ขอบเขตแผนที่ อำเภอ/จังหวัด/ประเทศ (สร้างจาก shapefile)
│   └── daily/
│       ├── 36t.js … 76t.js      ค่าฝุ่นรายวันของแต่ละสถานี (1 ไฟล์ต่อสถานี)
│       └── CM.js  LP.js  LI.js
├── lib/
│   ├── xlsx.full.min.js         ไลบรารีอ่าน/เขียน Excel (SheetJS, Apache-2.0) ใช้ในหลังบ้าน
│   └── xlsx-LICENSE.txt
├── docs/img/                    ภาพประกอบคู่มือ
└── tools/
    └── build_geo.py             สคริปต์แปลง shapefile → data/geo.js
```

ไม่ต้องอัปโหลดไฟล์ shapefile / Excel ต้นฉบับ (ถ้าอยากเก็บไว้ แนะนำโฟลเดอร์ `source/` — แต่ตรวจก่อนว่าแหล่งข้อมูลอนุญาตให้เผยแพร่)

> หน้าเว็บอ่านไฟล์ใน `data/` ผ่านแท็ก `<script>` จึงเปิด `index.html` ในเครื่องได้โดยไม่ต้องมีเซิร์ฟเวอร์ แต่ต้องวางโฟลเดอร์ `data/` (และ `lib/` สำหรับหลังบ้าน) ไว้ข้างๆ ไฟล์ HTML เสมอ

## เผยแพร่ด้วย GitHub Pages

1. สร้างรีโปบน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (Add file → Upload files ลากทั้งโฟลเดอร์ รวม `data/`, `lib/`, `docs/`, `tools/` และ `.nojekyll`) → Commit
2. **Settings → Pages** → Source: Deploy from a branch → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโป>/` (หลังบ้านที่ `.../admin.html` คู่มือที่ `.../manual.html`)

## อัปเดตข้อมูลโดยสรุป

หลังบ้านนำเข้าไฟล์ดิบรูปแบบเดิมได้โดยตรง และตรวจโครงสร้างให้เอง — รายละเอียดทั้งหมดอยู่ใน `manual.html`

| ไฟล์ดิบ | รูปแบบ | นำเข้าได้ที่ |
|---|---|---|
| `PM2_5_NorthernThailand_for_datatool.xlsx` | ชีต `PM2.5_<รหัสสถานี>` ปี/เดือนเป็นคอลัมน์ วันที่ 1–31 เป็นแถว | หลังบ้าน → นำเข้า / ส่งออก |
| `PM2_5-PSCF.xlsx` (ชีต `PM2.5_Combined`) | วันที่ × รหัสสถานี | หลังบ้าน → นำเข้า / ส่งออก |
| `11Station.xlsx` / `3Station.xlsx` | รหัส ที่ตั้ง จังหวัด ละติจูด ลองจิจูด | หลังบ้าน → นำเข้า / ส่งออก |
| `enso_config.csv` | RONI รายปี 3 ช่วง | หลังบ้าน → นำเข้า / ส่งออก |

ขั้นตอนทั่วไป: เปิด `admin.html` → แท็บ GitHub → **ดึงข้อมูลล่าสุด** → แท็บ นำเข้า / ส่งออก → เลือกไฟล์ → **อ่านตารางตัวอย่าง** (ใหม่ / เปลี่ยนค่า / เหมือนเดิม / ⚠) → ยืนยัน → ดูหน้าบ้านด้วยข้อมูลฉบับร่าง → แท็บ GitHub → **บันทึกขึ้น GitHub** → รอ 1–2 นาที

### สร้าง token ครั้งเดียว
GitHub → ไอคอนโปรไฟล์ → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
- Repository access: **Only select repositories** → เลือกรีโปนี้เท่านั้น
- Permissions → Repository permissions → **Contents: Read and write**
- ตั้งวันหมดอายุ (เช่น 90 วัน) แล้วคัดลอก token (ขึ้นต้น `github_pat_`) เก็บไว้ ห้ามส่งให้ผู้อื่นหรืออัปโหลดลงรีโป

### ข้อควรระวัง
- `admin.html` ไม่มีระบบล็อกอิน ที่แก้ในหน้านั้นเก็บในเบราว์เซอร์ของผู้แก้เท่านั้น ข้อมูลบนเว็บเปลี่ยนได้ก็ต่อเมื่อมี token ที่เขียนรีโปได้ — ถ้าไม่ต้องการให้คนทั่วไปเห็นหน้านี้ ไม่ต้องอัปโหลด `admin.html` ขึ้นรีโปสาธารณะ เก็บไว้เปิดในเครื่อง (ต้องมีโฟลเดอร์ `data/` และ `lib/` อยู่ข้างๆ)
- token เก็บในแท็บเบราว์เซอร์ (sessionStorage) จนปิดแท็บ ยกเว้นติ๊ก "จำ token" ซึ่งเก็บในเครื่องนั้น — อย่าติ๊กบนเครื่องสาธารณะ
- ถ้าสองคนแก้พร้อมกัน คนที่ commit ทีหลังจะทับไฟล์ที่ตัวเองแก้ (ไฟล์ที่ไม่ได้แก้ไม่ถูกแตะ) จึงควรดึงข้อมูลล่าสุดก่อนแก้เสมอ
- ส่วน commit ขึ้น GitHub ผ่านหลังบ้านทดสอบกับ GitHub API จำลอง แนะนำให้ลองกับรีโปทดลองก่อนใช้งานจริง

## แก้ไฟล์โดยตรงบน GitHub

เปิดไฟล์ใน `data/` → ไอคอนดินสอ (Edit) → แก้ → Commit
- `data/config.js` อ่านง่าย แก้ชื่อ/พิกัดสถานี ค่ามาตรฐาน RONI ได้เลย (เป็น JSON หลัง `window.PM25_CFG=`)
- `data/daily/<รหัสสถานี>.js` รูปแบบ `{ "ปี": [ 12 เดือน ], ... }` แต่ละเดือนเป็นอาร์เรย์ค่ารายวัน (`null` = ไม่มีข้อมูล) — ปริมาณมาก แนะนำให้แก้ผ่านหลังบ้านมากกว่า

## เปลี่ยนขอบเขตแผนที่ (shapefile)

ขอบเขตเก็บใน `data/geo.js` สร้างด้วย `tools/build_geo.py` (ครั้งแรกสร้างไว้ให้แล้วจากไฟล์ที่ให้มา)

```bash
pip install pyshp shapely pyproj
python tools/build_geo.py \
    --prov  source/9UNT_subprovince_1.shp \
    --world source/world-administrative-boundaries_1.shp \
    --config data/config.js \
    --out data/geo.js
```
- shapefile อำเภอต้องมีไฟล์ `.prj` อยู่ข้างๆ (ไม่มีให้ระบุ `--crs EPSG:32647`) และมีฟิลด์จังหวัด/อำเภอ/พื้นที่ (ชื่อฟิลด์ปรับด้วย `--f-prov --f-amp --f-area`)
- ปรับกรอบแผนที่ด้วย `--bbox LON0 LON1 LAT0 LAT1`
- ได้ `data/geo.js` ใหม่แล้ว: อัปโหลดทับในรีโป หรือเลือกไฟล์ที่แท็บ GitHub หัวข้อ 3 ของหลังบ้านแล้ว commit
- ชื่อจังหวัดใน shapefile ต้องตรงกับชื่อจังหวัดที่ใส่ในสถานี (`config.js`)

## นิยามที่ใช้ในเว็บ

- **เกินมาตรฐาน** = ค่าเฉลี่ยรายวันมากกว่าเกณฑ์: ไทย 37.5, WHO 15.0 µg/m³ (ปรับได้ที่หลังบ้าน)
- **ค่ารายจังหวัด** = เฉลี่ยของสถานีในจังหวัดนั้นในแต่ละวัน แล้วจึงสรุปรายเดือน/รายปี
- **กลุ่ม 8 จังหวัด / 9 จังหวัด** (คอลัมน์ซ้ายสุดของตาราง) = เฉลี่ยของค่ารายจังหวัดในกลุ่มของวันเดียวกัน (ทุกจังหวัดน้ำหนักเท่ากัน) แสดงเมื่ออย่างน้อย 80% ของจังหวัดในกลุ่มมีข้อมูลผ่านเกณฑ์ · ค่าเริ่มต้น 8 จังหวัด = ไม่รวมตาก ตั้งใหม่ได้ที่หลังบ้าน (แท็บ ค่ามาตรฐานและ RONI)
- **ช่วงของปี** (โหมดรายปี): ทั้งปี / ช่วงหมอกควัน ก.พ.–พ.ค. / นอกช่วง ม.ค., มิ.ย.–ธ.ค. (ตั้งเดือนใหม่ได้ที่หลังบ้าน)
- **เกณฑ์ข้อมูลครบ** (มุมขวาบน): ปี/เดือนที่มีข้อมูลน้อยกว่าเกณฑ์แสดง "—" (ชุด 11 สถานีเริ่มต้น ≥ 75% ของวัน ชุด 3 สถานีเป็นข้อมูลตัวอย่างไม่ครบทุกวัน จึงตั้งเป็น "มีข้อมูลก็แสดง")
- **Baseline** = Mean และ SD ตัวอย่าง (หาร n−1) ของปีที่เลือก เฉพาะปีที่ข้อมูลผ่านเกณฑ์ เลือกตามช่วงปีหรือประเภท ENSO (RONI ฤดูหมอกควัน/นอกฤดู/ทั้งปี) และเลือกเดือนที่ใช้คำนวณได้
- **RONI** จัดประเภท: > +0.5 = El Niño, < −0.5 = La Niña, นอกนั้น = Neutral

## ที่มาของข้อมูลชุดเริ่มต้น

สร้างจากไฟล์ดิบที่ให้มา ด้วยกติกาเดียวกับตัวนำเข้าในหลังบ้าน (ดูรายละเอียดข้อสังเกตในไฟล์ดิบที่ `manual.html` หัวข้อ "สิ่งที่พบในไฟล์ดิบชุดเดิม") ข้อควรทราบ:
- ชีต `PM2.5_68t` มีป้ายปี "2025" พิมพ์ซ้ำ (บล็อกที่สองควรเป็น 2026) ระบบตีความเป็น 2026 และเตือน ควรแก้ป้ายปีในไฟล์ Excel ต้นฉบับ (คอลัมน์ HJ)
- พิกัด 68t ตกใน อ.ทุ่งหัวช้าง แต่ที่ตั้งเขียน "อ.เมือง" ควรตรวจพิกัดซ้ำ
